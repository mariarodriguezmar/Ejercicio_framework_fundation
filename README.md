
Nombre del framework:Foundation for Sites.

Forma de instalación: Se utilizó la versión descargada de Foundation, usando las carpetas y archivos CSS y JavaScript que traía el proyecto. Se usó en especial se usó el archivo app.css para añadir el estilo propio.

Características útiles:

Diseño responsive: permitió adaptar la estructura de la landing a diferentes tamaños de pantalla mediante el sistema de grid y clases como `small-12`, `medium-6` y `large-up-4`.
Sistema de grid: facilitó la organización y distribución de los contenidos en filas y columnas sin tener que construir todo el sistema de maquetación desde cero.
Componentes responsive: permitió implementar una navegación adaptable para dispositivos móviles mediante `title-bar`, `top-bar` y `responsive-toggle`.

Componentes y utilidades utilizadas en la landing:

Grid: `grid-container`, `grid-x`, `cell` y `grid-margin-x` para estructurar las diferentes secciones y distribuir los contenidos.
Barra de navegación responsive: `top-bar`, `title-bar`, `menu` y `responsive-menu` para crear el menú adaptable.
Botones y componentes visuales: `button`, `button-group`, `label`, `card` y `callout` para construir botones de acción, etiquetas, tarjetas de servicios y el footer.
